# Naru 语言数字档案馆

Vue 3 + TypeScript + Vite。首页是一条横向展廊时间线：暖灰纸面、衬线排版、连续刻度和语言标志。图标与字体均本地提供，无运行时 CDN 请求或组件库依赖。

背景使用淡色纸面层次、档案格线、页码，以及每门语言的示意语法和年代水印。`LanguageTrace.vue` 中的代码片段为装饰用途的自写示例，不是历史文献摘录；均对辅助技术隐藏，不影响时间线的点击与键盘浏览。

## 本地运行

需要 Node.js 22.12+ 或 24+。

```powershell
cd E:\Dev\Vyx\Naru\web
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/ 。鼠标滚轮、横向触控、方向键和底部年代导航均可浏览时间线。默认呈现 12 个语言足迹，切换「全部版本」浏览全部馆藏。

```powershell
npm run check:archive
npm run check:wiki
npm run build
npm run check:build
npm run preview
```

构建结果在 `web/dist/`，生产预览使用 http://127.0.0.1:4173/ 。页面使用 hash 深链接，普通静态托管不需要 SPA 路由回退规则。部署时同时保留 `assets/`、`archive/` 和 `implementation/`。

`check:archive` 验证元数据与文件关联；`check:wiki` 验证全部条目的正文、引文、版本映射、实际导入关系，并通过 Vue 服务端渲染检查 22 个版本、12 个总览和索引 / 规则库页面。`check:build` 对原始条目卡、注记、史料、规则源码、示例与保存报告逐一核对 SHA-256。

## 馆藏来源

`scripts/catalog.mjs` 在开发和构建时读取项目根目录的 `historical/**/INDEX.md`、可选 `notes.md` 及 PDF/TXT/HTML 原件（含 Rationale 等无独立条目卡的子目录），生成 `virtual:archive-catalog`。统计、索引、筛选和下载由真实文件生成。

时间线展示所选语言或版本的年代，百科资料框保留原始文献年代。例如 Pascal 1970 包含后来的报告，K&R C 1984 包含 1986 年的厂商手册。展品说明由 `exhibits` 编目。新增档案时，须在 `content/encyclopedia.mjs` 补充正文与版本记录；`check:wiki` 会报告缺失的撰稿与引用。

## 百科正文与实现档案

`content/encyclopedia.mjs` 保存独立撰写的 12 个谱系正文、22 个版本导读及版本专节。内容按语言主题组织，包含程序解读、对照表、历史环境与参考文献；不是把 `INDEX.md` 或 PDF 填进正文。BASIC、C、Pascal 等版本之间有独立的导读、阅读重点与实现边界。原件与原始采集卡保留在文末的资料区。

`scripts/wiki.mjs` 扫描 `dialects/**/*.stx`，记录实际模块名、导入、syntax / effect 声明数、前端关系与 SHA-256。B、Pascal、C11 的实现档案关联真实规则、示例与记录；传递依赖支持循环，不把组成模块重复视为一门新语言。规则声明数不是覆盖率，共享模块不等于跨语言互操作。

保存的 C11 压力测试报告按文件日期显示，明确标为历史记录；前端构建不会重跑编译器。文献存在、规则存在与完整标准一致性分开呈现。B 的当前代码与旧实现文档存在差异，正文保留这条未解决的证据链。

主要深链接：`#/language/basic`（谱系总览）、`#/archive/basic%2F1964`（版本文章）、`#/index`（正文搜索与版本目录）、`#/dialects`（实际规则库）。文章为独立阅读页，带目录定位、语言资料框、版本切换、规则与示例、引文定位、相关阅读和分享。页面没有在线编译器或虚构的编辑历史。

原件按需下载，不加载进首页。构建复制原件的原始字节；HTML 史料在公开路径追加 `.txt`，避免作为网站脚本执行，下载仍保留原始文件名。开发服务器只提供目录中已登记的资料，并流式传输文件。

字体由 npm 包本地提供，中文使用系统字体。语言标志由 `src/components/LanguageMark.vue` 维护，颜色和样式在 `src/style.css` 中维护。FORTRAN 使用 Fortran-lang 社区标志，COBOL、C 使用 Devicon 收录的标志；其他馆藏采用语言名称字标。现代社区标志仅用于识别语言，不表示该标志在历史条目的年代已经存在，也不以某个编译器或后世方言的图标代指语言。资产来源与固定版本见 `public/language-marks/SOURCES.md`，许可证随构建一同保留。
