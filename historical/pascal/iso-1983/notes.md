# Pascal ISO 7185 考据注记

依据: `iso7185-1990.pdf`(验收规范,电子文本版)与 `pascal/1970/pascal-revised-report-1972.pdf`(Wirth 报告谱系)。
本文本为 ISO 条款 ↔ Naru 方言设施的映射表 + 两版本差异表。页码级引用 (待核对) 逐条补齐。

## 一、ISO 7185 的关键新增(相对 1972 修订报告)

| 特性 | ISO 状态 | 1972 报告状态 | Naru 对应 |
| --- | --- | --- | --- |
| 一致性数组参数(Level 1) | 标准特性 | 无 | 运行时边界数组(P0 核心项) |
| `pack/unpack` 标准过程 | 标准特性 | 无 | 数组方言组合 |
| 文件缓冲变量 `f^` + get/put | 精确定义(惰性求值) | 含糊 | 档案控制台/文件方言 |
| `input` 交互文件特例 | 有(look-ahead 语义) | 含糊 | 档案控制台方言 |
| `read/readln/write/writeln` | 定义为标准过程 | 实现定义 | 同上 |
| `page(f)` | 标准过程 | 无 | 同上(行印机语义) |
| `forward` 指令 | 形式化 | 通行但未定义 | 两遍收集签名(base 已有先例) |
| 字符串比较/填充规则 | 精确 | 含糊 | 字符串方言 |
| 标识符大小写不敏感 | 形式化 | 惯例 | 词法配置数据(lex.stx 模式) |

## 二、语法/语义重构要点

1. **类型同一性**:ISO 用声明位置定义类型同一(每个 `array[...] of ...` 书写处都是新类型),
   不是结构等价 → 类型方言按名义+书写位置建模,不用结构统一。
2. **set of**:基类型须为序数类型且基界有上限(实现可限制)→ 用位向量 lowering;
   `include/exclude` 等映射到整数字运算(operators.stx 已有 and/or/xor/shift)。
3. **variant records**:tag 字段约束访问合法性的检查是 ISO 语义的一部分 →
   variants.stx 之上加运行时 tag 检查选项(fidelity 模式可关)。
4. **goto**:标号限同块声明;跨块跳转非法 → 比 ALGOL 60 简单,cfg 库直接覆盖。
5. **过程/函数参数**:过程类型参数在 ISO 7185 里不得带自己的参数表
   (形式参数列表仅 §6.6.3.1 (待核对))→ 验收程序须遵守;扩展属 ISO 10206。
6. **常量表达式**:ISO 常量定义不含算术表达式(简单常量)→ 类型检查规则按字面量收口,
   与 C89 的整常量折叠形成对照。
7. **实数语义**:ISO 不定义浮点精度/舍入 → period float 库(IBM 370 S/360 十六进制浮点
   是 Pascal 的主流宿主之一)作为可选 fidelity 层,不进核心。

## 三、忠实度分档建议

- **iso7185 档**:按 ISO 7185 Level 0/1 完整实现,验收 = 标准正文 + 本注记。
- **wirth1972 档**:关闭 Level 1(一致性数组参数)与上表 ISO 新增项,行为对齐 1972 报告,
  用于演示"语言如何在标准化时被修改"——这是档案馆的招牌对比条目。
