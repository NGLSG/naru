# K&R C 考据注记(1978 第 1 版方言的行为基线)

依据: 《The C Programming Language》1st ed.(引用卡,未收原件)+ `c/89/c89-draft.txt` 中标记为
obsolescent/删除的特性反向推导。每条标注与 C89 草案的对照位置(§ 按草案编号,(待核对) 处逐条验证)。
本注记定义"kr 方言"与现有 `dialects/c11/` 的分叉面。

## 一、函数与类型系统

1. **旧式函数定义**:`int f(a, b) int a; char *b; { ... }`——参数表无类型、声明在函数体前。
   C89 §3.7.1 仍允许(标记 obsolescent);kr 方言以此为唯一函数形式,不实现原型。
2. **隐式函数声明**:调用未声明函数 = 返回 int 的函数(§3.3.2.2 里 C89 保留的行为)。
   kr 方言走"先收集签名再检查"的两遍关系时,未命中签名不报错而是合成 int 签名。
3. **默认 int**:省略类型说明符即 int(声明、函数返回、形参皆然)。
4. **实参提升**:无原型调用一律做 default argument promotions
   (char/short → int,float → double);调用点与定义点参数类型不一致 = 未定义。
   → 类型检查规则必须按"提升后比较"建模,不能按书写类型。
5. **无 void/enum/const/volatile/signed**:第 1 版正文均不存在;`entry` 是**保留但未实现**的关键字
   (K&R 原文明确 reserved)。方言词法把 entry 当保留字但语义层报"未实现",忠实还原。
6. **struct 赋值/传参/返回**:K&R 1 版不存在(只有指针传递);编译器在 1978–1988 间陆续加入,
   C89 §3.3.2.3 定为强制。kr 方言取"不允许"档,并记录这是与 msc40 条目(1986)的可核对差异点。

## 二、词法与常量

1. **字符串字面量可写**:K&R 时代字面量是可写 char 数组(惯例),C89 §3.1.4 改为未定义行为。
   kr 方言把字面量 lowering 到 `.data` 可写段(并在文档标注偏离现代实践)。
2. **无三角字符组**:trigraphs 是 C89 §2.1.1.2 新增;c11 方言里的 trigraph 预扫规则
   (lex.stx)在 kr 方言中关闭——这是同一词法设施"按方言配置"的现成案例。
3. **int 尺寸假设**:K&R 示例按 PDP-11 的 int=16 位书写;方言的目标语义锚定为
   C89 §2.2.4.2 的最小值域,而不是 PDP-11 ABI (待核对,以决定是否做 PDP-11 数值档)。

## 三、与 Naru c11 方言的复用关系

- 词法:复用 lex.stx 的通用扫描器,配置差异 = 关闭 trigraph、关闭 `++` 等 C89 新算符的保留
  (K&R 无 `+=`?——不对,K&R 1 版已有复合赋值;`+=` 存在 (待核对,以原书 §2.10 为准));
- 声明/表达式:复用 c11 的 decl 规则,关闭原型检查路径;
- 预处理:K&R 有 `#include/#define`,无 `#if/#elif`(§ 依据:K&R 附录 B);
  pp.stx 需按此裁剪;
- ABI:kr 方言默认按 PDP-11 调用约定语义建模?**不做**—— lowering 到 Windows x64 ABI,
  只保证语言层语义;ABI 差异记为本注记(忠实度边界:语言语义忠实,机器接口现代)。

## 四、验收来源

- K&R 1 版正文示例(K&R 手册章节编号引用,逐条人工转写——书籍版权限制,示例程序
  以我们重写等价物入库,不影印);
- `c/89/c89-draft.txt` 的 obsolescent 特性清单(§3.9.2 等)作为差异核对表;
- msc40-language-reference-1986.pdf 的"Language"章,核对 1986 年编译器已接受哪些
  新特性(结构赋值等)——用于标注 K&R→C89 的过渡态。

## 五、开放问题

1. `unsigned` 在 K&R 1 版的行为(有无 unsigned/signed 混算规则?) (待核对,原书 §2.7);
   —— M1 实现按 C 传统:unsigned 与同秩 signed 混算 → unsigned;u32+long(i64) → long
   (LP64 宿主规则,与 PDP-11 的 32 位 long 不同;记录在偏离表);
2. 位域的 K&R 语义与 C89 §3.5.2.1 的差异 (待核对);
3. `long float`(= double 的历史写法)是否收入 kr 方言 (待核对,原书 §4.1?);
4. **(M1 实现核对)** `+=` 系复合赋值确为 K&R 1 版内容 ✓;`entry` 按原书保留未实现 ✓;
   关键字表按 1 版 28 词收录(无 asm/fortran/const)✓;
   三角字符组关闭 ✓;`%ld` 在宿主 CRT 为 32 位(long=64 需 %lld,偏离表)✓。
