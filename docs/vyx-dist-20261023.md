## 较早的 SDK fb3e3320

编译器 SHA-256 为 `fb3e33200134f62ff3c7e7aa94ed1565d5b564c1c301eac9b104077657c5ad11`。

StringBuilder 崩溃复现在 O0/O2 输出 4429；Naru Release、语言 65/65、规则 155/155、项目 59/59、日志 11/11 通过。存储套件首轮一次 LLVM 内存分配失败，同输入复测及整组重跑为 68/68，报告为 `target/verification/storage-dist-20261023-rerun.json`。
