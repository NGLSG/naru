# historical/ 语言数字档案馆

用 Naru 重现历史上编程语言的考据层。每个条目 = 考据对象 + 原件 + 与 Naru 方言的关系。
本目录只收史料;方言实现(`.stx`)和验收程序放在方言工程侧,INDEX 卡里互相引用。

## 目录命名

`语言/谱系或方言/年份`,谱系可省略。目录名小写、ASCII、用连字符。

```

c/kr/1984      K&R 事实标准分化期(约 1983–1987:厂商方言、X3J11 成立前夜)
c/89           ANSI C89(1989)
c/99           ISO C99(1999)
c/11           ISO C11(2011,N1570 最终草案)
algol/58       ALGOL 58(IAL,初步报告 1958,引用卡)
algol/60       ALGOL 60(1963 修订报告 + 1976 修改报告原件;1960 原报告为引用卡)
lisp/1960-recursion  McCarthy 递归函数论文(1960)
lisp/1.5/1962  LISP 1.5 程序员手册(1962)
basic/1964     Dartmouth BASIC 原始手册(1964-10)
basic/1968     BASIC 第 4 版(1968-01,MAT 与字符串扩展)
b/1972         Users' Reference to B
bcpl           BCPL(Richards)
pascal/1970    Wirth 报告谱系(1972 修订报告、P-machine、Pascal-P 原件;1971 论文为引用卡)
```

年份对应"规范/报告的形成年",不是重印年。同一语言新增条目时先在此表登记。

## 条目规范

每个条目目录**必须**包含 `INDEX.md`(条目卡),模板:

```markdown
# <名称>

- 类型: 规范 | 草案 | 报告 | 手册 | 论文 | 教材 | 程序
- 主体/作者:
- 年份:
- 考据对象: 本条目主张重现的行为以哪份文献为准(一句话)
- 许可: 公有领域 | 自由流传 | 版权保留-仅引用
- 来源: <原始 URL>
- 获取日期: YYYY-MM-DD
- 文件清单:
  - `xxx.pdf` — <一句话说明>
- 与 Naru 方言的关系: 对应哪个方言/哪些验收用例;尚未实现时写"未开始"
- 备注: 版本、已知扫描缺陷、与其他条目的差异
```

## 硬性规则

1. **原件保持原格式**(PDF/HTML/TXT),不改写、不删节;文件名 slug 化(小写-连字符)。
   HTML 原件旁可另存 `*.extract.md` 作为摘录,原件优先。
2. **版权分级**:
   - 公有领域 / 有明确再分发许可或授权的材料 → 可在记录依据后随档案发布。
   - 作者、机构或 bitsavers 提供公开访问，只能证明可获取，不能据此推断再分发许可。
     既有“自由流传”标签需逐项核对；在确认前，源码预览包只保留条目卡与原创注记，不包含原件或抽取副本。
   - 版权保留且仍在售(ISO/ANSI 正式标准、在版书籍如 K&R、Jensen & Wirth、Iverson)→
     **只记引用卡**(标题、ISBN/编号、官方购买渠道),不放扫描件、不留下载链接。
3. 每条目可选 `notes.md` 记考据注记:规范内部矛盾、实现分歧(如各 FORTRAN 编译器差异)、
   重构时必须二选一的点。
4. 引用卡(许可 = 版权保留-仅引用)同样要有 INDEX.md,文件清单写"无原件"。
5. 二进制(PDF/扫描图)放入前核对字节数与类型;损坏或截断的文件不得入库。

## 与方言工程的对接

- `docs/c11.md` 引用的 WG14 N1570 对应 `historical/c/11/`。
- 方言 INDEX 反向引用:`dialects/<lang>/README.md` 应引用其考据条目路径。
- 重构验收产生的黄金输出与史料的对应关系记录在方言侧,不在本目录重复。
