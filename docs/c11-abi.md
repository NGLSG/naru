# Windows x64 C ABI

`c11.abi` 为函数声明、定义、调用、返回值和变参读取提供统一分类。源类型保持不变，物理传递方式由目标规则决定。

## 聚合传递

1、2、4、8 字节的记录、联合体和复数载体使用整数容器。其他聚合由调用方创建间接副本，返回值通过隐藏的 `sret` 指针写入。副本在入口块分配，至少 16 字节对齐。柔性数组记录使用独立分类策略，布尔标量保留扩展属性。

直接调用、函数指针、无原型及旧式调用复用这些分类。被调用方先解码传入值，再初始化 C 形参对象；返回值写入先于 VLA 等栈清理。

允许不完整聚合类型出现的声明使用仅地址的物理接口，调用和定义处仍要求完整布局。指针所指类型可以保持不完整。

## 变参

`va_start`、`va_end`、`va_copy` 和类型化读取接入实际资源头接口。Windows `va_list` 每次前进一个 8 字节槽，按参数分类加载和解码。宏与 typedef 来自系统 `stdarg.h`。

## 测试

```powershell
python tests/c11_abi.py
python tests/c11_abi_interop.py
python tests/c11_nonprototype_abi.py
```

独立对象测试让 Naru 分别担任调用者和被调用者，在 O0/O2 下与 Clang/MSVC 对象链接。重点包括过对齐聚合、复数载体、padding、重定位、柔性成员及变参。其他目标需要独立的 ABI 策略。
